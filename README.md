# Guitar_Teacher

App personale per studiare la chitarra con un maestro: lezioni da 30 o 60 minuti, percorso a livelli con ripasso a intervalli, valutazione di note, accordi, ritmo, orecchio e assolo. Strumenti: metronomo, circolo delle quinte, manico, accordatore.

Si apre da GitHub Pages; su iPhone e iPad si aggiunge alla schermata Home da Safari.
